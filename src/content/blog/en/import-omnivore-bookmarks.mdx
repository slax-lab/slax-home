Omnivore shut down on November 15, 2024, but an Omnivore export file still holds everything you need to start again. You can import Omnivore bookmarks into Slax Reader by uploading that one file. Importing is free.

## Before you start

- **Your Omnivore export.** It is a ZIP that holds JSON files named like `metadata_0_to_50.json`. Omnivore [closed after its team joined ElevenLabs](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs), so you can't make a new export. Look in Downloads, email and cloud backups for "omnivore" or "metadata_".
- **A Slax Reader account.** [Sign up or log in](https://r.slax.com).
- **Don't unzip it.** Slax Reader reads the ZIP directly.

## Import your Omnivore export in five steps

1. **Open Settings.** Log in, hover over your avatar and click **Setting**.
2. **Go to Data.** Click **Data**, then find the **Import third-party data** card.
3. **Click the Omnivore button.** Press **Import third-party data Omnivore** and pick your ZIP.
4. **Wait for the upload.** A window shows "Unzipping file..." then "Uploading file...", and ends with **omnivore data imported successfully, please wait a moment**. Your links are then saved in the background.
5. **Follow the progress.** Click **View import progress**. When Status reads **Complete**, open your Inbox.

Slax Reader re-fetches every page rather than copying a list, so a big library takes a while. You can leave the window and come back.

## What moves over

| From Omnivore | In Slax Reader |
|---|---|
| Link, title, description | Saved bookmark |
| Thumbnail | Kept |
| Labels | Become tags |
| Archived items | Arrive in your Inbox, so archive them again |
| Original saved date | Not kept; links are dated from the day you import them |
| Highlights and notes | Not included, so keep your export file |

## Fix links that failed

Pages that no longer exist, or that block automated visits, can't be saved.

1. In **Import progress**, click the number under **Failed**.
2. In the **Import Failures** window, open any link to check if the page is still online.
3. If it is, save it again with the [Slax Reader browser extension](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd).
4. Tick the leftovers and click **Batch Delete**, or use **Delete All**.

**Upload does nothing?** Check that you chose the original ZIP and that it holds `metadata_..._to_....json` files. If you picked a single JSON file, try the ZIP instead.

## FAQ

### Is importing free?
Yes. You can import Omnivore bookmarks into Slax Reader for free.

### Can I still export from Omnivore?
No. The hosted service is gone, so you need an export you saved before it closed.

### Is Slax Reader open source like Omnivore?
Yes, under the Apache 2.0 license. The code is on [GitHub](https://github.com/slax-lab).
