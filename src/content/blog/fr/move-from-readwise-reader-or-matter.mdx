Si vous voulez quitter Readwise Reader ou Matter, vous pouvez emporter votre liste de lecture dans Slax Reader gratuitement. Aucune des deux applications n’a encore d’import en un clic vers Slax : la méthode est donc courte et identique pour les deux. Récupérez la liste de vos liens, puis enregistrez-les. Cela marche aussi pour la plupart des autres applications de lecture différée.

## Avant de commencer

- **Un compte Slax Reader.** [Inscrivez-vous ou connectez-vous](https://r.slax.com).
- **Une idée de ce que vous voulez garder.** Inutile de tout transférer. Beaucoup ne prennent que ce qu’ils comptent encore lire.

## Étape 1 : récupérer la liste de vos liens

Choisissez votre application. Dans tous les cas, vous obtenez un simple fichier texte nommé `links.txt`, avec un lien par ligne.

### Depuis Readwise Reader

1. Ouvrez votre page **Account profile** et choisissez **Export Library as CSV** sous « Export account data ». Vous pouvez aussi ouvrir la Command Palette et chercher « Generate CSV export ». Le [guide d’export de Readwise](https://docs.readwise.io/reader/docs/faqs/exporting) donne les étapes à jour.
2. Ouvrez le CSV dans un tableur, copiez la colonne **url** et collez-la dans `links.txt`.

### Depuis Matter

Regardez d’abord si les réglages de Matter proposent un export. S’il ne vous donne pas de fichier avec vos liens, il faudra le faire à la main : ouvrez chaque article à garder, copiez son adresse web d’origine et collez-la dans `links.txt`. Si vous avez surligné un article, l’export Markdown des surlignages de Matter incluait un lien vers l’original, ce qui peut vous éviter un peu de copier-coller.

### Depuis une autre application

Cherchez une option d’export dans les réglages de l’application, en général un fichier CSV, HTML ou JSON. Copiez la colonne des liens dans `links.txt`. S’il n’y a pas d’export, rassemblez les liens à la main, comme avec Matter.

## Étape 2 : enregistrer les liens dans Slax Reader

**Quelques liens seulement ?** Ouvrez-les un par un et cliquez sur l’[extension de navigateur Slax Reader](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd). La page est enregistrée en un clic.

**Beaucoup de liens ?** Utilisez la ligne de commande. Installez-la et connectez-vous avec une API key récupérée dans vos réglages Slax Reader. Gardez cette clé pour vous.

```bash
npx @slax-lab/reader-cli@latest install
reader-cli login
```

Ensuite, sur Mac ou Linux :

```bash
while read -r url; do reader-cli add "$url" --tags "from-readwise"; done < links.txt
```

Sous Windows PowerShell :

```powershell
Get-Content links.txt | ForEach-Object { reader-cli add $_ --tags "from-readwise" }
```

Chaque lien est enregistré un par un et tagué, pour que tout votre lot soit facile à retrouver. Utilisez `from-matter` pour les liens Matter, ou le tag de votre choix. Avec une très longue liste, lancez-la par petits morceaux et vérifiez votre Inbox entre deux.

## Ce qui est transféré

| Depuis votre ancienne application | Dans Slax Reader |
|---|---|
| Liens web | Favoris enregistrés avec une copie fraîche de chaque page, tagués avec le nom de votre lot |
| Date d’enregistrement d’origine | Non conservée ; les liens prennent la date à laquelle vous les enregistrez |
| Surlignages et notes | Restent dans l’ancienne application, gardez donc son export |
| Éléments qui ne sont pas des pages web, comme des fichiers envoyés | Non couverts ici |

## FAQ

### Transférer ma bibliothèque est-il gratuit ?
Oui. Vous pouvez transférer votre bibliothèque dans Slax Reader gratuitement.

### Vais-je perdre mes surlignages ?
Ils ne sont pas transférés, mais ils ne disparaissent pas. Ils restent dans votre ancienne application, gardez-en donc un export.

### Pourquoi une ligne de commande et pas un bouton d’import ?
Les réglages proposent des boutons d’import pour Pocket et Omnivore uniquement. Pour les autres applications, enregistrer les liens est le plus rapide.

## Vous venez plutôt de Pocket ou d’Omnivore ?
