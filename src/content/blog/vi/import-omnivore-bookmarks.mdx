Omnivore đã đóng cửa vào ngày 15 tháng 11 năm 2024, nhưng file xuất dữ liệu Omnivore vẫn chứa mọi thứ bạn cần để bắt đầu lại. Bạn có thể nhập dấu trang Omnivore vào Slax Reader chỉ bằng cách tải lên đúng một file đó. Việc nhập là miễn phí.

## Trước khi bắt đầu

- **File xuất dữ liệu Omnivore của bạn.** Đó là một file ZIP chứa các file JSON có tên kiểu `metadata_0_to_50.json`. Omnivore [đóng cửa sau khi đội ngũ gia nhập ElevenLabs](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs), nên bạn không thể tạo file xuất mới. Hãy tìm "omnivore" hoặc "metadata_" trong Downloads, email và các bản sao lưu đám mây.
- **Một tài khoản Slax Reader.** [Đăng ký hoặc đăng nhập](https://r.slax.com).
- **Đừng giải nén.** Slax Reader đọc thẳng file ZIP.

## Nhập dữ liệu Omnivore trong năm bước

1. **Mở Settings.** Đăng nhập, di chuột lên ảnh đại diện và nhấp **Setting**.
2. **Vào Data.** Nhấp **Data**, rồi tìm thẻ **Import third-party data**.
3. **Nhấp nút Omnivore.** Bấm **Import third-party data Omnivore** và chọn file ZIP.
4. **Chờ tải lên.** Một cửa sổ hiển thị "Unzipping file..." rồi "Uploading file...", và kết thúc với **omnivore data imported successfully, please wait a moment**. Sau đó các link sẽ được lưu ở chế độ nền.
5. **Theo dõi tiến độ.** Nhấp **View import progress**. Khi Status hiện **Complete**, hãy mở Inbox của bạn.

Slax Reader tải lại từng trang thay vì chỉ sao chép một danh sách, nên thư viện lớn sẽ mất một lúc. Bạn có thể rời cửa sổ và quay lại sau.

## Những gì được chuyển sang

| Trong Omnivore | Trong Slax Reader |
|---|---|
| Link, tiêu đề, mô tả | Dấu trang đã lưu |
| Ảnh thu nhỏ | Được giữ lại |
| Labels | Trở thành thẻ |
| Mục đã lưu trữ | Vào Inbox, nên hãy lưu trữ lại |
| Ngày lưu gốc | Không giữ lại; link được ghi ngày bạn nhập |
| Đánh dấu và ghi chú | Không bao gồm, nên hãy giữ file xuất dữ liệu |

## Xử lý link bị lỗi

Những trang không còn tồn tại, hoặc chặn truy cập tự động, sẽ không lưu được.

1. Trong **Import progress**, nhấp vào con số dưới **Failed**.
2. Trong cửa sổ **Import Failures**, mở link bất kỳ để xem trang còn trực tuyến không.
3. Nếu còn, lưu lại bằng [tiện ích trình duyệt Slax Reader](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd).
4. Đánh dấu những mục còn lại và nhấp **Batch Delete**, hoặc dùng **Delete All**.

**Tải lên mà không có phản hồi?** Hãy kiểm tra bạn đã chọn file ZIP gốc và bên trong có các file `metadata_..._to_....json`. Nếu bạn chọn một file JSON lẻ, hãy thử lại với file ZIP.

## Câu hỏi thường gặp

### Nhập dữ liệu có miễn phí không?
Có. Bạn có thể nhập dấu trang Omnivore vào Slax Reader miễn phí.

### Tôi còn xuất dữ liệu từ Omnivore được không?
Không. Dịch vụ lưu trữ đã ngừng, nên bạn cần một file xuất đã lưu trước khi nó đóng cửa.

### Slax Reader có mã nguồn mở như Omnivore không?
Có, theo giấy phép Apache 2.0. Mã nguồn có trên [GitHub](https://github.com/slax-lab).
