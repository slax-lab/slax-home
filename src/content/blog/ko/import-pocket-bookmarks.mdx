Pocket은 문을 닫았지만, 저장해 둔 링크까지 함께 사라질 필요는 없습니다. Pocket 내보내기 파일을 갖고 있다면, 한 번만 업로드해서 Pocket 북마크를 Slax Reader로 가져올 수 있습니다. 가져오기는 무료이고, 시간이 걸리는 부분은 Slax Reader가 백그라운드에서 처리합니다.

## 시작하기 전에

- **Pocket 내보내기 파일.** `part_000000.csv` 같은 이름의 CSV 파일이 하나 이상 들어 있는 ZIP입니다. Pocket은 2025년 7월 8일에 저장 기능을 중단했고, [마지막 내보내기 기한은 2025년 11월 12일이었습니다](https://www.vice.com/en/article/mozilla-pocket-gets-one-month-reprieve/). 그래서 새 파일은 더 이상 받을 수 없습니다. 다운로드 폴더, 이메일, 클라우드 저장소에서 "pocket"을 검색해 보세요.
- **Slax Reader 계정.** [가입 또는 로그인](https://r.slax.com).
- **ZIP은 압축을 풀지 마세요.** Slax Reader가 직접 엽니다.

## 다섯 단계로 Pocket 내보내기 가져오기

1. **설정 열기.** [r.slax.com](https://r.slax.com)에 로그인하고, 아바타에 마우스를 올린 뒤 **Setting**을 클릭합니다.
2. **Data로 이동.** 설정 메뉴에서 **Data**를 클릭하고, **Import third-party data** 카드를 찾습니다.
3. **Pocket 버튼 클릭.** **Import third-party data Pocket**을 누르면 파일 선택 창이 열립니다.
4. **ZIP 선택.** "Unzipping file..."에 이어 "Uploading file..."이 표시됩니다. 끝나면 **pocket data imported successfully, please wait a moment** 메시지가 나옵니다. 파일이 도착했다는 뜻입니다. 링크는 이어서 백그라운드에서 저장됩니다.
5. **진행 상황 확인.** **View import progress**를 클릭합니다. **Import progress** 창의 Status가 Pending, 퍼센트가 표시되는 Processing을 거쳐 **Complete**로 바뀌면 Inbox를 열어 보세요.

진행되는 동안 창을 닫고 계속 읽어도 됩니다. 몇백 개의 링크는 금방 끝납니다. 몇천 개라면 시간이 더 걸리는데, Slax Reader가 모든 페이지를 다시 불러와 새 사본을 저장하기 때문입니다.

## 옮겨지는 것

| Pocket에서 | Slax Reader에서 |
|---|---|
| 링크와 제목 | 북마크로 저장 |
| 태그 | 태그 |
| 보관한 항목 | 그대로 보관됨 |
| 원래 저장한 날짜 | 유지되지 않음. 가져온 날짜로 기록됨 |
| 하이라이트와 메모 | 포함되지 않으니 내보내기 파일을 보관하세요 |

Pocket 내보내기에는 링크와 정보만 들어 있고, 글 본문은 없습니다. 이미 웹에서 삭제된 페이지는 다시 불러올 수 없습니다.

## 일부 링크가 실패했다면

몇 개는 꼭 생깁니다. 삭제된 페이지, 자동 접속을 막는 사이트, 로그인이 필요한 링크 등입니다.

1. **Import progress**에서 **Failed** 열의 숫자를 클릭합니다.
2. **Import Failures** 창에 목록이 나옵니다. 원래 페이지를 열어 아직 있는지 확인하세요.
3. 있다면 [Slax Reader 브라우저 확장 프로그램](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)으로 다시 저장합니다.
4. 항목을 선택한 뒤 **Batch Delete**를 클릭하거나, **Delete All**로 목록을 비웁니다.

**파일을 골랐는데 아무 일도 없나요?** 원래의 ZIP인지, 안에 `part_000000.csv` 같은 파일이 있는지 확인하세요. 이름을 바꾸거나 다시 압축한 ZIP은 인식되지 않습니다.

## 자주 묻는 질문

### 가져오기는 무료인가요?
네. Pocket 북마크는 무료로 Slax Reader에 가져올 수 있습니다.

### 지금도 Pocket에서 내보낼 수 있나요?
아니요. 내보내기 기간은 2025년 11월 12일에 끝났습니다. 그전에 저장해 둔 파일이 필요합니다.
