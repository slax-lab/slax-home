Pocket과 Omnivore는 모두 서비스를 종료했지만, 저장해 둔 링크까지 함께 잃을 필요는 없습니다. 내보내기 파일을 보관해 두었다면 한 번의 업로드로 Pocket이나 Omnivore 북마크를 Slax Reader로 가져올 수 있습니다. 가져오기는 무료이고, 시간이 걸리는 부분은 Slax Reader가 백그라운드에서 처리합니다.

## 시작하기 전에

- **내보내기 파일.** 두 앱 모두 ZIP으로 내보냅니다. 압축을 풀지 마세요. Slax Reader가 대신 엽니다.
  - **Pocket:** `part_000000.csv` 같은 이름의 CSV 파일이 하나 이상 들어 있는 ZIP입니다. Pocket은 2025년 7월 8일에 저장 기능을 멈췄고, [마지막 내보내기 기한은 2025년 11월 12일이었습니다](https://www.vice.com/en/article/mozilla-pocket-gets-one-month-reprieve/).
  - **Omnivore:** `metadata_0_to_50.json` 같은 이름의 JSON 파일이 들어 있는 ZIP입니다. Omnivore는 [팀이 ElevenLabs에 합류한 뒤 2024년 11월 15일에 종료했습니다](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs).
- **새 내보내기는 불가능합니다.** 두 앱 모두 이제 새 파일을 만들 수 없으니, 저장해 둔 파일을 찾아보세요. 다운로드 폴더, 이메일, 클라우드 저장소에서 "pocket", "omnivore", "metadata_"로 검색해 보세요.
- **Slax Reader 계정.** [가입 또는 로그인](https://r.slax.com).
- **용량 제한.** ZIP은 최대 25 MiB까지입니다.

## 다섯 단계로 내보내기 파일 가져오기

1. **설정 열기.** [r.slax.com](https://r.slax.com)에 로그인하고 아바타에 마우스를 올린 뒤 **Setting**을 클릭합니다.
2. **Data로 이동.** 설정 메뉴에서 **Data**를 클릭하고 **Import third-party data** 카드를 찾습니다.
3. **Pocket 또는 Omnivore 클릭.** 떠나는 앱의 버튼을 고르면 파일 선택 창이 열립니다.
4. **ZIP 선택.** "Unzipping file..."에 이어 "Uploading file..."이 표시됩니다. 끝나면 **File received** 메시지가 나옵니다. 이제 북마크가 백그라운드에서 가져와지고 있습니다.
5. **진행 상황 확인.** **View import progress**를 클릭합니다. Status가 Pending에서 퍼센트가 붙은 Processing을 거쳐 **Complete**로 바뀌면 Inbox를 열어 보세요.

진행되는 동안 창을 닫고 계속 읽어도 됩니다. 링크 몇백 개는 금방 끝납니다. 수천 개는 더 오래 걸리는데, Slax Reader가 모든 페이지를 다시 가져와 새 사본을 저장하기 때문입니다. 가져오기는 동시에 최대 다섯 개까지 실행할 수 있습니다.

## 옮겨지는 항목

| 내보내기 파일의 항목 | Pocket | Omnivore |
|---|---|---|
| 링크와 제목 | ✅ | ✅ |
| 태그 | ✅ | ✅ 라벨이 태그가 됩니다 |
| 설명과 썸네일 | ✗ | ✅ |
| 보관된 항목 | ✅ 보관 상태 유지 | ✗ Inbox로 들어오니 다시 보관하세요 |
| 원래 저장 날짜 | ✗ 가져온 날짜로 표시 | ✗ 가져온 날짜로 표시 |
| 하이라이트와 메모 | ✗ 내보내기 파일을 보관하세요 | ✗ 내보내기 파일을 보관하세요 |

내보내기 파일에는 링크가 들어 있을 뿐, 기사 본문은 없습니다. Slax Reader가 각 페이지를 다시 가져오므로, 이미 웹에서 삭제된 페이지는 되살릴 수 없습니다.

## 일부 링크가 실패하면

몇 개는 꼭 생깁니다. 삭제된 페이지, 자동 방문을 막는 사이트, 로그인이 필요한 링크 등입니다.

1. **Import progress**에서 **Failed** 열의 숫자를 클릭합니다.
2. **Import Failures** 창에 목록이 나옵니다. 원래 페이지를 열어 아직 있는지 확인하세요.
3. 있다면 [Slax Reader 브라우저 확장 프로그램](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)으로 다시 저장합니다.
4. 남은 항목을 체크하고 **Batch Delete**를 클릭하거나, **Delete All**로 목록을 비웁니다.

**파일을 골라도 아무 일도 없나요?** 원본 ZIP인지 확인하세요. Pocket ZIP에는 `part_000000.csv` 같은 파일이, Omnivore ZIP에는 `metadata_..._to_....json` 파일이 들어 있어야 합니다. 압축을 푼 단일 파일이나, 이름을 바꾸거나 다시 만든 ZIP은 인식되지 않습니다.

## 자주 묻는 질문

### 가져오기는 무료인가요?
네. Pocket과 Omnivore 북마크를 Slax Reader로 무료로 가져올 수 있습니다.

### 아직 Pocket이나 Omnivore에서 내보낼 수 있나요?
아니요. Pocket의 내보내기 기간은 2025년 11월 12일에 끝났고, Omnivore의 호스팅 서비스도 사라졌습니다. 예전에 저장해 둔 파일이 필요합니다.

### Slax Reader도 Omnivore처럼 오픈 소스인가요?
네, Apache 2.0 라이선스입니다. 코드는 [GitHub](https://github.com/slax-lab)에 있습니다.

## 다른 앱에서 옮기시나요?

Slax Reader는 [Readwise Reader, Instapaper, Pinboard](/blog/import-readwise-instapaper-pinboard/)도 원클릭으로 가져올 수 있습니다. Matter, Raindrop 등 다른 앱에서 오신다면 [링크를 직접 옮기는 방법](/blog/move-from-matter-and-other-read-later-apps/)을 확인하세요. 아직 비교 중이라면 Slax Reader와 [Pocket](/reader/alternatives/pocket/), [Omnivore](/reader/alternatives/omnivore/) 비교를 보거나, [나중에 읽기 앱이 계속 문을 닫는 이유](/blog/read-it-later-history/)를 읽어 보세요.

[Slax Reader를 열고](https://r.slax.com) 가져오기를 시작하세요.
