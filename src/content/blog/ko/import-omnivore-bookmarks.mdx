Omnivore는 2024년 11월 15일에 서비스를 종료했지만, Omnivore 내보내기 파일에는 다시 시작하는 데 필요한 모든 것이 들어 있습니다. 그 파일 하나만 업로드하면 Omnivore 북마크를 Slax Reader로 가져올 수 있습니다. 가져오기는 무료입니다.

## 시작하기 전에

- **Omnivore 내보내기 파일.** `metadata_0_to_50.json` 같은 이름의 JSON 파일이 들어 있는 ZIP입니다. Omnivore는 [팀이 ElevenLabs에 합류한 뒤 종료](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs)되어, 새 내보내기는 더 이상 만들 수 없습니다. 다운로드 폴더, 이메일, 클라우드 백업에서 "omnivore"나 "metadata_"를 검색해 보세요.
- **Slax Reader 계정.** [가입 또는 로그인](https://r.slax.com).
- **압축을 풀지 마세요.** Slax Reader가 ZIP을 바로 읽습니다.

## 다섯 단계로 Omnivore 내보내기 가져오기

1. **설정 열기.** 로그인한 뒤 아바타에 마우스를 올리고 **Setting**을 클릭합니다.
2. **Data로 이동.** **Data**를 클릭하고 **Import third-party data** 카드를 찾습니다.
3. **Omnivore 버튼 클릭.** **Import third-party data Omnivore**를 누르고 ZIP을 선택합니다.
4. **업로드 기다리기.** 창에 "Unzipping file...", 이어서 "Uploading file..."이 표시되고, 마지막에 **omnivore data imported successfully, please wait a moment**가 나옵니다. 링크는 그다음 백그라운드에서 저장됩니다.
5. **진행 상황 확인.** **View import progress**를 클릭합니다. Status가 **Complete**가 되면 Inbox를 열어 보세요.

Slax Reader는 목록을 복사하는 대신 모든 페이지를 다시 불러오기 때문에, 라이브러리가 크면 시간이 좀 걸립니다. 창을 떠났다가 나중에 다시 와도 됩니다.

## 옮겨지는 것

| Omnivore에서 | Slax Reader에서 |
|---|---|
| 링크, 제목, 설명 | 북마크로 저장 |
| 썸네일 | 유지 |
| Labels | 태그가 됨 |
| 보관한 항목 | Inbox로 들어오니 다시 보관하세요 |
| 원래 저장한 날짜 | 유지되지 않음. 가져온 날짜로 기록됨 |
| 하이라이트와 메모 | 포함되지 않으니 내보내기 파일을 보관하세요 |

## 실패한 링크 해결하기

더 이상 존재하지 않는 페이지나 자동 접속을 막는 페이지는 저장할 수 없습니다.

1. **Import progress**에서 **Failed** 아래의 숫자를 클릭합니다.
2. **Import Failures** 창에서 링크를 열어 페이지가 아직 온라인인지 확인합니다.
3. 온라인이라면 [Slax Reader 브라우저 확장 프로그램](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)으로 다시 저장합니다.
4. 남은 항목을 선택하고 **Batch Delete**를 클릭하거나, **Delete All**을 사용합니다.

**업로드해도 아무 반응이 없나요?** 원래의 ZIP을 골랐는지, 안에 `metadata_..._to_....json` 파일이 있는지 확인하세요. JSON 파일 하나만 골랐다면 ZIP으로 다시 시도해 보세요.

## 자주 묻는 질문

### 가져오기는 무료인가요?
네. Omnivore 북마크는 무료로 Slax Reader에 가져올 수 있습니다.

### 지금도 Omnivore에서 내보낼 수 있나요?
아니요. 호스팅 서비스가 종료되었으니, 종료 전에 저장해 둔 내보내기 파일이 필요합니다.

### Slax Reader도 Omnivore처럼 오픈 소스인가요?
네, Apache 2.0 라이선스입니다. 코드는 [GitHub](https://github.com/slax-lab)에 있습니다.

## 다른 앱에서 옮겨 오시나요?

Slax Reader는 [Pocket](/blog/import-pocket-bookmarks/) 내보내기도 가져올 수 있고, [Readwise Reader나 Matter에서 옮겨 오기](/blog/move-from-readwise-reader-or-matter/)에 대한 짧은 가이드도 있습니다. 비교 중이라면 [Omnivore 대안으로서의 Slax Reader](/reader/alternatives/omnivore/)를 보거나, [나중에 읽기 앱의 역사](/blog/read-it-later-history/)를 읽어 보세요.

[Slax Reader를 열고](https://r.slax.com) 가져오기를 시작하세요.
