Slax Reader는 [Pocket과 Omnivore](/blog/import-pocket-omnivore-bookmarks/), 그리고 [Readwise Reader, Instapaper, Pinboard](/blog/import-readwise-instapaper-pinboard/)를 원클릭으로 가져올 수 있습니다. Matter처럼 가져오기 버튼이 없는 앱은 조금 더 손이 가지만 여전히 간단합니다. 링크 목록을 뽑은 다음 저장하면 됩니다. 무료입니다.

## 시작하기 전에

- **Slax Reader 계정.** [가입 또는 로그인](https://r.slax.com).
- **무엇을 남길지 대략적인 생각.** 전부 옮길 필요는 없습니다. 아직 읽을 생각인 것만 가져오는 분도 많습니다.

## 1단계: 링크 목록 뽑기

어떤 앱을 떠나든, 결국 한 줄에 링크 하나씩 적힌 `links.txt`라는 텍스트 파일을 만들게 됩니다.

### Matter에서

먼저 Matter 설정에 내보내기 옵션이 있는지 확인하세요. 링크가 담긴 파일을 받을 수 없다면 직접 해야 합니다. 남기고 싶은 기사를 하나씩 열어 원래 웹 주소를 복사하고 `links.txt`에 붙여 넣으세요. 하이라이트한 기사라면 Matter의 하이라이트 Markdown 내보내기에 원문 링크가 들어 있었으니, 복사하는 수고를 덜 수 있습니다.

### Raindrop, Cubox, GoodLinks 등 다른 앱에서

앱 설정에서 내보내기 옵션을 찾으세요. 보통 CSV, HTML, JSON 파일입니다. 파일을 열어 링크가 있는 열이나 줄을 복사해 `links.txt`에 붙여 넣으세요. 내보내기가 없다면 Matter처럼 직접 링크를 모으면 됩니다.

## 2단계: Slax Reader에 링크 저장하기

**링크가 몇 개뿐이라면?** 하나씩 열고 [Slax Reader 브라우저 확장 프로그램](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)을 클릭하세요. 클릭 한 번으로 페이지가 저장됩니다.

**링크가 많다면?** 명령줄을 쓰세요. Node.js 22 또는 24가 필요합니다. Slax Reader의 **Settings → Skills + CLI → Generate and copy**에서 API 키를 받은 다음, CLI를 설치하고 그 키로 로그인합니다. 키는 남에게 보여 주지 마세요.

```bash
npx @slax-lab/reader-cli@latest install
reader-cli login
```

그다음 Mac이나 Linux에서:

```bash
while read -r url; do reader-cli add "$url" --tags "from-matter"; done < links.txt
```

Windows PowerShell에서:

```powershell
Get-Content links.txt | ForEach-Object { reader-cli add $_ --tags "from-matter" }
```

링크가 하나씩 저장되고 태그가 붙으니, 한꺼번에 옮긴 묶음을 쉽게 찾을 수 있습니다. `from-matter`는 `from-raindrop`이나 원하는 태그로 바꿔도 됩니다. 목록이 아주 길다면 작게 나눠 실행하고 중간중간 Inbox를 확인하세요.

## 옮겨지는 항목

| 기존 앱 | Slax Reader에서 |
|---|---|
| 웹 링크 | 각 페이지의 새 사본과 함께 저장된 북마크, 묶음 이름 태그 포함 |
| 원래 저장 날짜 | 유지되지 않음, 저장한 날짜로 표시 |
| 하이라이트와 메모 | 기존 앱에 남으니 내보내기 파일을 보관하세요 |
| 업로드한 파일처럼 웹 페이지가 아닌 항목 | 여기서는 다루지 않음 |

## 자주 묻는 질문

### 라이브러리를 옮기는 건 무료인가요?
네. 라이브러리를 Slax Reader로 무료로 옮길 수 있습니다.

### 하이라이트가 사라지나요?
옮겨지지는 않지만 사라지지도 않습니다. 기존 앱에 남아 있으니 내보내기 파일을 보관해 두세요.

### 왜 가져오기 버튼이 아니라 명령줄인가요?
설정에는 Pocket, Omnivore, Readwise Reader, Instapaper, Pinboard용 가져오기 버튼이 있습니다. 그 밖의 앱은 링크를 저장하는 것이 가장 빠른 방법입니다.
