Omnivore tutup pada 15 November 2024, tapi file ekspor Omnivore masih menyimpan semua yang kamu butuhkan untuk mulai lagi. Kamu bisa mengimpor bookmark Omnivore ke Slax Reader dengan mengunggah satu file itu. Impor gratis.

## Sebelum mulai

- **Ekspor Omnivore kamu.** Bentuknya ZIP berisi file JSON dengan nama seperti `metadata_0_to_50.json`. Omnivore [tutup setelah timnya bergabung dengan ElevenLabs](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs), jadi kamu tidak bisa membuat ekspor baru. Cari "omnivore" atau "metadata_" di Downloads, email, dan cadangan cloud kamu.
- **Akun Slax Reader.** [Daftar atau masuk](https://r.slax.com).
- **Jangan diekstrak.** Slax Reader membaca ZIP-nya langsung.

## Impor ekspor Omnivore dalam lima langkah

1. **Buka Settings.** Masuk, arahkan mouse ke avatar kamu, lalu klik **Setting**.
2. **Buka Data.** Klik **Data**, lalu cari kartu **Import third-party data**.
3. **Klik tombol Omnivore.** Tekan **Import third-party data Omnivore** dan pilih ZIP kamu.
4. **Tunggu unggahan.** Jendela menampilkan "Unzipping file..." lalu "Uploading file...", dan diakhiri dengan **omnivore data imported successfully, please wait a moment**. Setelah itu link kamu disimpan di latar belakang.
5. **Pantau progresnya.** Klik **View import progress**. Saat Status menunjukkan **Complete**, buka Inbox kamu.

Slax Reader mengambil ulang setiap halaman, bukan sekadar menyalin daftar, jadi koleksi besar butuh waktu. Kamu bisa meninggalkan jendela dan kembali nanti.

## Apa saja yang ikut pindah

| Di Omnivore | Di Slax Reader |
|---|---|
| Link, judul, deskripsi | Bookmark tersimpan |
| Thumbnail | Tetap ada |
| Labels | Menjadi tag |
| Item yang diarsipkan | Masuk ke Inbox, jadi arsipkan lagi |
| Tanggal simpan asli | Tidak dipertahankan; link diberi tanggal hari kamu mengimpor |
| Sorotan dan catatan | Tidak termasuk, jadi simpan file ekspor kamu |

## Perbaiki link yang gagal

Halaman yang sudah tidak ada, atau yang memblokir kunjungan otomatis, tidak bisa disimpan.

1. Di **Import progress**, klik angka di bawah **Failed**.
2. Di jendela **Import Failures**, buka link mana pun untuk mengecek apakah halamannya masih online.
3. Kalau masih, simpan lagi dengan [ekstensi browser Slax Reader](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd).
4. Centang sisanya lalu klik **Batch Delete**, atau gunakan **Delete All**.

**Unggahan tidak bereaksi?** Pastikan kamu memilih ZIP asli dan isinya ada file `metadata_..._to_....json`. Kalau kamu memilih satu file JSON saja, coba pakai ZIP-nya.

## FAQ

### Apakah impor gratis?
Ya. Kamu bisa mengimpor bookmark Omnivore ke Slax Reader secara gratis.

### Apakah masih bisa ekspor dari Omnivore?
Tidak. Layanan hosted-nya sudah tidak ada, jadi kamu butuh ekspor yang disimpan sebelum layanan tutup.

### Apakah Slax Reader open source seperti Omnivore?
Ya, dengan lisensi Apache 2.0. Kodenya ada di [GitHub](https://github.com/slax-lab).
