Pocket sudah tutup, tapi link yang kamu simpan tidak harus ikut hilang. Kalau kamu masih menyimpan file ekspor Pocket, kamu bisa mengimpor bookmark Pocket ke Slax Reader dengan sekali unggah. Impor gratis, dan bagian yang lambat dikerjakan Slax Reader di latar belakang.

## Sebelum mulai

- **File ekspor Pocket kamu.** Bentuknya ZIP berisi satu atau beberapa file CSV dengan nama seperti `part_000000.csv`. Pocket berhenti menyimpan pada 8 Juli 2025, dan [batas akhir ekspornya adalah 12 November 2025](https://www.vice.com/en/article/mozilla-pocket-gets-one-month-reprieve/), jadi kamu tidak bisa membuat file baru lagi. Cari "pocket" di folder Downloads, email, dan penyimpanan cloud kamu.
- **Akun Slax Reader.** [Daftar atau masuk](https://r.slax.com).
- **Biarkan ZIP tetap tertutup.** Jangan diekstrak. Slax Reader yang akan membukanya.

## Impor ekspor Pocket dalam lima langkah

1. **Buka Settings.** Masuk di [r.slax.com](https://r.slax.com), arahkan mouse ke avatar kamu, lalu klik **Setting**.
2. **Buka Data.** Klik **Data** di navigasi pengaturan. Cari kartu bernama **Import third-party data**.
3. **Klik tombol Pocket.** Tekan **Import third-party data Pocket**. Pemilih file akan terbuka.
4. **Pilih ZIP kamu.** Kamu akan melihat "Unzipping file..." lalu "Uploading file...". Setelah selesai, muncul pesan **pocket data imported successfully, please wait a moment**. Artinya file sudah sampai. Link kamu lalu disimpan di latar belakang.
5. **Cek progresnya.** Klik **View import progress**. Jendela **Import progress** menampilkan Status Pending, lalu Processing dengan persentase, lalu **Complete**. Setelah itu buka Inbox kamu.

Kamu bisa menutup jendela dan lanjut membaca selama proses berjalan. Beberapa ratus link selesai dengan cepat. Ribuan link butuh waktu lebih lama, karena Slax Reader mengambil ulang setiap halaman untuk menyimpan salinan baru.

## Apa saja yang ikut pindah

| Di Pocket | Di Slax Reader |
|---|---|
| Link dan judul | Bookmark tersimpan |
| Tag | Tag |
| Item yang diarsipkan | Tetap diarsipkan |
| Tanggal simpan asli | Tidak dipertahankan; link diberi tanggal hari kamu mengimpor |
| Sorotan dan catatan | Tidak termasuk, jadi simpan file ekspor kamu |

Ekspor Pocket berisi link dan detailnya, bukan teks artikel. Halaman yang sudah dihapus dari web tidak bisa diambil lagi.

## Kalau ada link yang gagal

Pasti ada beberapa: halaman yang dihapus, situs yang memblokir kunjungan otomatis, link yang butuh login.

1. Di **Import progress**, klik angka di kolom **Failed**.
2. Jendela **Import Failures** menampilkan daftarnya. Buka halaman aslinya untuk melihat apakah masih ada.
3. Kalau masih ada, simpan lagi dengan [ekstensi browser Slax Reader](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd).
4. Klik **Batch Delete** (setelah mencentang item) atau **Delete All** untuk mengosongkan daftar.

**Tidak terjadi apa-apa setelah memilih file?** Pastikan itu ZIP asli dan berisi file seperti `part_000000.csv`. ZIP yang sudah diganti nama atau dibuat ulang tidak akan dikenali.
