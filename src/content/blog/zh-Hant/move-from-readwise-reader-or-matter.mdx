如果你想從 Readwise Reader 或 Matter 搬走，可以免費把閱讀列表帶進 Slax Reader。這兩個 App 目前都還沒有一鍵匯入到 Slax 的功能，所以方法很簡單，而且兩者通用：先拿到你的連結列表，再把它們保存進來。這個方法對大多數其他稍後讀 App 也適用。

## 開始之前

- **一個 Slax Reader 帳號。** [註冊或登入](https://r.slax.com)。
- **大概想好要留下哪些。** 不必全部搬過來。很多人只帶走自己還打算讀的內容。

## 第 1 步：拿到你的連結列表

選擇你的 App。不管用哪種方式，最後都會得到一個叫 `links.txt` 的純文字檔，每行一個連結。

### 從 Readwise Reader

1. 打開 **Account profile** 頁面，在 "Export account data" 下選擇 **Export Library as CSV**。你也可以打開 Command Palette，搜尋 "Generate CSV export"。最新步驟見 [Readwise 的匯出指南](https://docs.readwise.io/reader/docs/faqs/exporting)。
2. 用試算表軟體打開 CSV，複製 **url** 這一欄，貼到 `links.txt` 裡。

### 從 Matter

先在 Matter 的設定裡找找有沒有匯出選項。如果它沒有給你一個連結檔案，就只能手動了：打開每篇想保留的文章，複製它的原始網址，貼到 `links.txt` 裡。如果你在某篇文章裡畫過線，Matter 的畫線 Markdown 匯出裡通常會附上原文連結，可以省掉一些複製的功夫。

### 從其他 App

在 App 設定裡找匯出選項，通常是 CSV、HTML 或 JSON 檔案。把連結那一欄複製到 `links.txt`。如果沒有匯出功能，就像 Matter 那樣手動收集連結。

## 第 2 步：在 Slax Reader 裡保存連結

**只有幾個連結？** 逐一打開，點擊 [Slax Reader 瀏覽器擴充功能](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)，一鍵就能保存網頁。

**連結很多？** 用命令列。安裝後，用 Slax Reader 設定裡的 API key 登入。請妥善保管這個 key，不要外流。

```bash
npx @slax-lab/reader-cli@latest install
reader-cli login
```

然後，在 Mac 或 Linux 上：

```bash
while read -r url; do reader-cli add "$url" --tags "from-readwise"; done < links.txt
```

在 Windows PowerShell 上：

```powershell
Get-Content links.txt | ForEach-Object { reader-cli add $_ --tags "from-readwise" }
```

每個連結會逐筆保存並加上標籤，所以整批內容很容易找到。Matter 的連結可以用 `from-matter`，或任何你喜歡的標籤。如果列表很長，分成幾小批來跑，每跑完一批去 Inbox 看一眼。

## 哪些內容會搬過來

| 舊 App 裡的 | 在 Slax Reader 裡 |
|---|---|
| 網頁連結 | 保存為書籤，每個網頁都有一份新副本，並加上你的批次標籤 |
| 原始保存日期 | 不保留；日期記為保存當天 |
| 畫線和筆記 | 留在舊 App 裡，請保留好它的匯出檔案 |
| 不是網頁的內容，例如上傳的檔案 | 本指南不涉及 |

## 常見問題

### 搬家免費嗎？
免費。把你的內容搬進 Slax Reader 不收費。

### 我的畫線會不見嗎？
不會搬過來，但也不會消失。它們留在舊 App 裡，記得匯出一份保存好。

### 為什麼用命令列，而不是匯入按鈕？
設定裡目前只有 Pocket 和 Omnivore 的匯入按鈕。對其他 App 來說，直接保存連結是最快的方法。

## 從 Pocket 或 Omnivore 過來？

[打開 Slax Reader](https://r.slax.com)，開始搬你的連結吧。
