Omnivore 已於 2024 年 11 月 15 日關閉，但一份 Omnivore 匯出檔案裡仍有你重新開始所需的一切。只要上傳這一個檔案，就能把 Omnivore 書籤匯入 Slax Reader。匯入免費。

## 開始之前

- **你的 Omnivore 匯出檔案。** 它是一個 ZIP，裡面是名稱類似 `metadata_0_to_50.json` 的 JSON 檔案。Omnivore [在團隊加入 ElevenLabs 後關閉](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs)，所以已經無法再產生新的匯出。在下載資料夾、信箱和雲端備份裡搜尋 "omnivore" 或 "metadata_" 試試。
- **一個 Slax Reader 帳號。** [註冊或登入](https://r.slax.com)。
- **不要解壓縮。** Slax Reader 會直接讀取 ZIP。

## 五步匯入 Omnivore 匯出檔案

1. **打開設定。** 登入後，把滑鼠移到頭像上，點擊 **Setting**。
2. **進入 Data。** 點擊 **Data**，找到 **Import third-party data** 卡片。
3. **點擊 Omnivore 按鈕。** 點 **Import third-party data Omnivore**，選擇你的 ZIP。
4. **等待上傳。** 視窗會先顯示 "Unzipping file..."，再顯示 "Uploading file..."，最後出現 **omnivore data imported successfully, please wait a moment**。之後連結會在背景逐筆保存。
5. **查看進度。** 點擊 **View import progress**。當 Status 顯示 **Complete** 時，打開你的 Inbox。

Slax Reader 會重新抓取每個網頁，而不只是複製一份列表，所以內容多的話需要一點時間。你可以先離開視窗，稍後再回來看。

## 哪些內容會搬過來

| Omnivore 裡的 | 在 Slax Reader 裡 |
|---|---|
| 連結、標題、描述 | 保存為書籤 |
| 縮圖 | 保留 |
| Labels | 變成標籤 |
| 已封存的內容 | 會出現在 Inbox 裡，需要重新封存 |
| 原始保存日期 | 不保留；日期記為匯入當天 |
| 畫線和筆記 | 不包含，請保留好匯出檔案 |

## 處理匯入失敗的連結

已經不存在的網頁，或封鎖自動存取的網頁，無法保存。

1. 在 **Import progress** 裡，點擊 **Failed** 下的數字。
2. 在 **Import Failures** 視窗裡，打開任一連結，看看網頁是否還在線上。
3. 如果還在，用 [Slax Reader 瀏覽器擴充功能](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)重新保存。
4. 勾選剩下的項目，點擊 **Batch Delete**，或者用 **Delete All**。

**上傳沒有反應？** 確認你選的是原始 ZIP，而且裡面有 `metadata_..._to_....json` 檔案。如果你選的是單一 JSON 檔案，改用 ZIP 試試。

## 常見問題

### 匯入免費嗎？
免費。把 Omnivore 書籤匯入 Slax Reader 不收費。

### 現在還能從 Omnivore 匯出嗎？
不能。託管服務已經關閉，你需要用關閉前保存的匯出檔案。

### Slax Reader 和 Omnivore 一樣開源嗎？
是的，採用 Apache 2.0 授權。程式碼在 [GitHub](https://github.com/slax-lab) 上。
