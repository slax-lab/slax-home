スマートフォンで記事を読む時間は、たいてい細切れです。エレベーターを待つ間、電車の中、列に並んでいる数分間。そこで今回の Slax Reader アップデートでは、ひとつのことに集中しました。スマートフォンを手に取ったら、すぐ続きを読めることです。

新しいアプリは、端末にある内容を先に表示し、同期はバックグラウンドで行います。記事は自動で端末に保存されるので、通信がなくても読めます。検索も作り直し、保存の方法も増えました。新機能と使い方を順に紹介します。

## 開けばすぐ読める

以前は、同期が終わるまで内容が表示されないことがよくありました。今はライブラリとアバターが端末に保存されているので、アプリを開くとすぐに表示され、同期はバックグラウンドで進みます。

記事も同じです。ダウンロード済みの記事は、前回読んでいた位置からそのまま開きます。画面が白く点滅することも、外部画像の読み込みを待つこともありません。

**使い方：**設定は不要です。リストの下に「Continue reading」が表示されたら、タップすると読んでいた記事に戻れます。

## オフラインでも読める

アプリは記事の本文、画像、PDF をバックグラウンドで自動ダウンロードするので、地下鉄や飛行機の中でも読み続けられます。オフラインで追加したリンクも失われません。すぐにリストに表示され、オンラインに戻ると保存が完了します。

**使い方：**

1. サイドバーを開き、「Settings」に進みます。
2. オフラインキャッシュの設定で、端末に残す記事数を選びます。上限を超えると、最も古いキャッシュが端末から削除されます。クラウド上の永久スナップショットには影響しません。
3. 容量を節約したい場合は、画像のダウンロードをオフにします。
4. 「Clear Cache」で使用容量を確認し、不要なものを削除できます。自動でキャッシュされた本文と画像には影響しません。

## 新しい検索

検索は独立した全画面ページになりました。入力すると、端末内の記事、コレクション、RSS がすぐに見つかります。検索を実行すると、保存した記事の本文も検索し、各結果にサイト名と保存日を表示します。

**使い方：**

1. Inbox 上部の「Add」ボタンの隣にある検索アイコンをタップします。
2. キーワードを入力すると、端末内の結果がすぐに表示されます。
3. タグで絞り込むには、`#` を入力してタグを選ぶか、下部のタグピッカーから選びます。
4. 「Search」をタップすると、保存した記事の本文も検索します。

## 保存の方法が増えました

読みたいものを見つけたら、次の方法で保存できます。

- **共有シート：**Safari、Chrome などのアプリで「共有」をタップし、Slax Reader を選びます。
- **リンクを貼り付け：**アプリで「Add」をタップし、リンクを貼り付けて確定します。
- **Siri とショートカット（iOS）：**Siri に「Save to Slax Reader」と話しかけるか、ショートカットアプリの「Save link」アクションを使います。

iOS では、アプリを開かずに記事を探すこともできます。システム検索に、最近保存した記事が最大 500 件表示され、タップするとそのまま開きます。iOS 18 以降が必要です。Slax Reader がシステムに渡すのはタイトルとサイト名だけで、本文、メモ、完全なリンクはアプリ内にとどまります。使わない場合は、「Settings」でシステム検索への表示をオフにできます。

## スマートフォンで PDF、RSS、YouTube を読む

この 3 つは Labs の機能で、初期状態ではオフです。オンにするとすぐ使えます。

**PDF：**

1. 「Settings」で PDF の Labs をオンにします。
2. 「Add」をタップし、PDF ファイルのインポートを選びます。1 回に 1 ファイル、最大 50 MiB で、アップロードには通信が必要です。
3. PDF を開くと、読む、ハイライトする、コメントするといった操作ができます。ダウンロード済みの PDF はオフラインでも読めます。

**RSS：**

1. 「Settings」で RSS の Labs をオンにします。
2. RSS フィードで「Add」をタップし、RSS または Atom のアドレスを入力します。
3. フィードを切り替えながら、じっくり読みたい記事を Inbox に保存します。

**YouTube：**

1. Web 版の「Settings → Labs」で YouTube 動画をオンにします。今のところ、これは Web 版からのみオンにできます。
2. 記事と同じように、YouTube のリンクを Slax Reader に共有します。
3. 動画を開き、右上の「More」から「Transcript」をタップします。再生中の行がハイライトされ、どの行でもタップするとそこへ移動します。

## 使い心地が良くなったところ

- リストの記事をスワイプすると、スターを付けたりアーカイブしたりできます。
- 記事内の画像をタップすると、拡大、写真への保存、共有ができます。
- ハイライト、コメント、AI の概要とアウトラインはアプリでも使え、メモは Web 版と同期します。
- 問題があれば、サイドバーの「Feedback」からお知らせください。最近のログを添付するかどうかは選べます。この項目は初期状態でオフです。
