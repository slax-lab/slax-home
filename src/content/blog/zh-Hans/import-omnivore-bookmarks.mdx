Omnivore 已于 2024 年 11 月 15 日关闭，但一份 Omnivore 导出文件里仍有你重新开始所需的一切。只要上传这一个文件，就能把 Omnivore 书签导入 Slax Reader。导入免费。

## 开始之前

- **你的 Omnivore 导出文件。** 它是一个 ZIP，里面是名字类似 `metadata_0_to_50.json` 的 JSON 文件。Omnivore [在团队加入 ElevenLabs 后关闭](https://5typos.net/2024/10/29/omnivore-is-shutting-down-and-team-joining-elevenlabs)，所以已经无法再生成新的导出。在下载文件夹、邮箱和云端备份里搜索 "omnivore" 或 "metadata_" 试试。
- **一个 Slax Reader 账号。** [注册或登录](https://r.slax.com)。
- **不要解压。** Slax Reader 会直接读取 ZIP。

## 五步导入 Omnivore 导出文件

1. **打开设置。** 登录后，把鼠标移到头像上，点击 **Setting**。
2. **进入 Data。** 点击 **Data**，找到 **Import third-party data** 卡片。
3. **点击 Omnivore 按钮。** 点 **Import third-party data Omnivore**，选择你的 ZIP。
4. **等待上传。** 窗口会先显示 "Unzipping file..."，再显示 "Uploading file..."，最后出现 **omnivore data imported successfully, please wait a moment**。之后链接会在后台逐条保存。
5. **查看进度。** 点击 **View import progress**。当 Status 显示 **Complete** 时，打开你的 Inbox。

Slax Reader 会重新抓取每个网页，而不只是复制一份列表，所以内容多的话需要一点时间。你可以先离开窗口，稍后再回来看。

## 哪些内容会搬过来

| Omnivore 里的 | 在 Slax Reader 里 |
|---|---|
| 链接、标题、描述 | 保存为书签 |
| 缩略图 | 保留 |
| Labels | 变成标签 |
| 已归档的内容 | 会出现在 Inbox 里，需要重新归档 |
| 原始保存日期 | 不保留；日期记为导入当天 |
| 高亮和笔记 | 不包含，请保留好导出文件 |

## 处理导入失败的链接

已经不存在的网页，或屏蔽自动访问的网页，无法保存。

1. 在 **Import progress** 里，点击 **Failed** 下的数字。
2. 在 **Import Failures** 窗口里，打开任意链接，看看网页是否还在线。
3. 如果还在，用 [Slax Reader 浏览器扩展](https://chromewebstore.google.com/detail/slax-reader/gdnhaajlomjkhahnmiijphnodkcfikfd)重新保存。
4. 勾选剩下的条目，点击 **Batch Delete**，或者用 **Delete All**。

**上传没有反应？** 确认你选的是原始 ZIP，并且里面有 `metadata_..._to_....json` 文件。如果你选的是单个 JSON 文件，改用 ZIP 试试。

## 常见问题

### 导入免费吗？
免费。把 Omnivore 书签导入 Slax Reader 不收费。

### 现在还能从 Omnivore 导出吗？
不能。托管服务已经关闭，你需要用关闭前保存的导出文件。

### Slax Reader 和 Omnivore 一样开源吗？
是的，采用 Apache 2.0 协议。代码在 [GitHub](https://github.com/slax-lab) 上。
